# Dev и прод

| | **Dev** (`.venv/bin/python -m app.gui` / `cli` / `watch`) | **Прод** (`Kadr.app`) |
|---|---|---|
| Признак | `sys.frozen` нет | собрано PyInstaller |
| Настройки | `.env` (важнее) + `dev/settings.json` | `~/Library/Application Support/Kadr/settings.json` |
| Ключ Anthropic | `.env` | Связка ключей |
| Папки | `dev/{inbox,done,failed,logs}` | `~/Movies/Kadr/{Входящие,Готово,Ошибки}` |
| Модели | `dev/models` | `~/Library/Application Support/Kadr/models` |
| Логи | `dev/logs` | `~/Library/Logs/Kadr` |
| Quick Action | «Сделать субтитры (dev)» | «Сделать субтитры» |
| Заголовок окна | `Kadr 1.0.1 — dev` | `Kadr 1.0.1` |

Обе версии можно держать запущенными одновременно: lock-файлы в разных `DATA`.

# Git

- `main` — то, что можно выпустить. Задача → ветка `fix/…` или `feat/…` → merge в `main`.
- Каждая правка пишется строкой в `CHANGELOG.md` → «Не выпущено».
- Версия живёт только в `app/__init__.py` (`__version__`).

# Релиз

```bash
tools/release.sh          # 1.0.0 → 1.0.1, исправления
tools/release.sh minor    # 1.0.1 → 1.1.0, новое
```

Скрипт поднимает версию, закрывает раздел CHANGELOG, коммитит, ставит тег `vX.Y.Z`, собирает `.app`,
пушит и выкладывает `Kadr.zip` в GitHub Releases. Старую версию для знакомых — брать из Releases.

Патч к старой версии (уже раздали 1.2.0, а `main` ушёл вперёд):

```bash
git switch -c hotfix/1.2 v1.2.0   # правка + CHANGELOG, затем вручную версия 1.2.1, тег v1.2.1, сборка
```
