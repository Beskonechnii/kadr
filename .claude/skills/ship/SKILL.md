---
name: ship
description: Слить готовую ветку feat/… или fix/… в main и запушить. Вызывать, когда Стас говорит «ship», «слей ветку в main», «влей и запушь». Релиз — отдельно, скилл release.
---

1. Ветка — `feat/…` или `fix/…`, `git status` чистый (незакоммиченное — закоммитить, если это часть задачи, иначе спросить).
   В `CHANGELOG.md` → «## Не выпущено» есть строка про изменение — нет, дописать в ветке.
2. `git checkout main && git pull --ff-only && git merge --no-ff <ветка> -m "Merge <ветка>: <суть по-русски>"`
   (+ строка соавторства). Конфликт — разобрать, не `-X ours/theirs`.
3. `git push origin main`, затем `git status -sb` — `main...origin/main` без ahead/behind. Не сошлось — так и написать.
4. Ветку не удалять. В ответе — хеш merge-коммита и что ждёт релиза в «Не выпущено»; релиз — только по слову Стаса.
