# Изменения

Версии — `MAJOR.MINOR.PATCH`: патч — исправления, minor — новое без поломки настроек, major — ломает совместимость.
Пока идёт разработка — `0.x`; 1.0 — первая стабильная версия.

## Не выпущено

## 0.0.4 — 2026-10-23

- `tools/bench.py` — бенч качества по эталонам в `test/`: WER распознавания, нарезка реплик, chrF и судья Claude
  для перевода, время и память; история в `test/bench-history.jsonl`. Редактор считает правки реплик
  (`edits` в `project.json`), `bench.py --edits` показывает правок на минуту видео.
- Перевод: разговорные названия мест по-английски стандартно («Питер» → St. Petersburg, а не Peter);
  реплике, которую не успеть прочитать, переводчик получает лимит знаков — английский больше не выходит
  длиннее русского. По судье на монологе Claude 4,53 → 4,67, быстрых реплик 57% → 17%; Qwen без изменений (4,5).
  Пробовал второй проход «отшлифовать английский» для Qwen: +0,05 балла в пределах шума за +30% времени, откатил.

## 0.0.3 — 2026-10-21

- В редакторе: **⌘Z / ⇧⌘Z**; удалить реплику (✕, ⌘⌫) и **добавить** в паузу («+ Реплика»); ↑↓ по репликам,
  `[` `]` — край реплики на позицию видео.
- **Сомнительные слова**: где распознавание не уверено, под репликой — «? слово»; клик проигрывает его.
  Работает для видео, обработанных с этой версии.
- **Найти и заменить** во всех репликах (⌘F); «Запомнить для новых видео» — замена дальше делается сама
  после распознавания и перевода.
- «Только проблемные»; поправили русский — метка «RU изменён» и «Перевести изменённые» разом;
  у быстрых реплик ⚡ — «сократить»: перевод заново под время реплики.

## 0.0.2 — 2026-10-21

- В редакторе: реплику можно **разрезать** (⌘B — по курсору в тексте или по месту видео) и **склеить**
  со следующей, **края тянуть** на дорожке (колёсико — масштаб, края липнут к началу и концу голоса),
  **перевести заново** одну реплику после правки русского текста.
- Английские слова в Reels, подсветке и караоке загораются, когда человек говорит, а не в паузах: паузы ищутся
  по звуку, слова раскладываются по слогам. Старые проекты подхватывают это при открытии в редакторе.
- **Редактор субтитров**: реплики RU/EN правятся в списке и прямо на кадре, субтитр перетаскивается мышью,
  превью совпадает с итоговым видео, «Пересобрать видео» — за секунды без повторного распознавания.
- **Пресеты внешнего вида**: Классика, Плашка, Reels (капс по 3 слова с подсветкой), Минимал, Караоке,
  Двуязычный; свои пресеты; пресет по умолчанию отдельно для 9:16, 1:1 и 16:9; сетка безопасных зон
  Reels / TikTok / Shorts / YouTube. Шрифты свои: Montserrat, Inter, Rubik, Oswald, Unbounded.
- Вертикальные ролики с iPhone (в файле 1920×1080 + поворот) теперь определяются как вертикальные.
- Рядом с результатом — `project.json`; старые проекты открываются в редакторе по SRT.
- `BURN_STYLE` в `.env` больше не используется — внешний вид задают пресеты.
- **Нагрузка** в окне: Эконом / Баланс / Максимум. Модели больше не висят в памяти всё время: грузятся к видео
  и выгружаются после простоя (в «Максимуме» — всегда наготове). В «Балансе» пик памяти 6,2 GB вместо 11.
- Связка ключей больше не спрашивает пароль при каждом запуске: ключ API читается, только когда выбран Claude.
- Строка «Сейчас» в окне: сколько памяти и ЦП занимает Kadr, какие модели в памяти, давление памяти Mac.
- Приложение называется **Kadr**. При первом запуске настройки, модели, ключ API, папки в «Фильмах» и Quick Action
  переносятся со «Субтитров» сами. Старое «Субтитры» из «Программ» удалите; автозапуск при входе включите заново.
- Dev-версия ставит Quick Action «Сделать субтитры (dev)» и больше не перетирает действие из `.app`.
- Версия в заголовке окна; в dev-режиме — пометка «— dev».
