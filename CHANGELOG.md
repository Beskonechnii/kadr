# Изменения

Версии — `MAJOR.MINOR.PATCH`: патч — исправления, minor — новое без поломки настроек, major — ломает совместимость.

## Не выпущено

- **Нагрузка** в окне: Эконом / Баланс / Максимум. Модели больше не висят в памяти всё время: грузятся к видео
  и выгружаются после простоя (в «Максимуме» — всегда наготове). В «Балансе» пик памяти 6,2 GB вместо 11.
- Связка ключей больше не спрашивает пароль при каждом запуске: ключ API читается, только когда выбран Claude.
- Строка «Сейчас» в окне: сколько памяти и ЦП занимает Kadr, какие модели в памяти, давление памяти Mac.
- Приложение называется **Kadr**. При первом запуске настройки, модели, ключ API, папки в «Фильмах» и Quick Action
  переносятся со «Субтитров» сами. Старое «Субтитры» из «Программ» удалите; автозапуск при входе включите заново.
- Dev-версия ставит Quick Action «Сделать субтитры (dev)» и больше не перетирает действие из `.app`.
- Версия в заголовке окна; в dev-режиме — пометка «— dev».
